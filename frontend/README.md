# SaludClick — Frontend

Este directorio contiene las páginas HTML, estilos, imágenes y JavaScript del cliente. No contiene credenciales ni código de base de datos.

## Ejecutar
1. Inicia el backend siguiendo `../backend/README.md`.
2. Abre esta carpeta en VS Code y ejecuta `index.html` con Live Server (recomendado: `http://127.0.0.1:5500`). También puedes usar cualquier servidor estático local.
3. La URL de API se configura en `js/config.js`; por defecto es `http://localhost:3000`.

No abras los HTML con `file://`, porque los módulos JavaScript y las peticiones HTTP pueden fallar.
